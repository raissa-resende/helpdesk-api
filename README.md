# Helpdesk API

API de suporte (helpdesk) multi-tenant com triagem de tickets assistida por IA.

## Stack
NestJS · TypeScript · Node · PostgreSQL · Docker · Jest · GitHub Actions

## Objetivo
Projeto de estudo e portfólio com foco em arquitetura em camadas, testes,
segurança e CI/CD.

## Status
Em desenvolvimento. Roadmap: autenticação e tenants, tickets e regras de
negócio, Docker e deploy, triagem com IA.
